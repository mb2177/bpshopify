# Shopify Research Bot: Telegram и веб-кабинет

Бот проверяет идеи небольшого товарного бизнеса на Shopify для двух рынков: **США (USA)** и **ОАЭ (UAE)**. Дропшиппинг исключён.

- **Telegram** нужен только для ввода. Пришлите идею текстом, ссылкой, фото или голосом. Бот подтвердит приём, а когда разбор будет готов, пришлёт оценку **X/10**, вывод, первый рынок и **ссылку на полный разбор**.
- **Сайт** хранит всё: историю идей, полные разборы, конкурентов, производство, экономику, версии, источники.

## Как пользоваться

| Действие | Как |
|---|---|
| Новая идея | Написать боту: «Проверь идею: кастомные футболки для свадеб, конкуренты в Дубае». Можно прислать ссылку, фото или альбом. |
| Уточнить идею | Ответить (reply) на сообщение бота об идее: «а если партия 50 шт?», «найди конкурентов в Дубае», «не хотим покупать оборудование». То же можно сделать на сайте в разделе «Уточнить». |
| Поменять цифры | Сайт → идея → «Экономика» → «Изменить параметры». Пересчёт мгновенный, без платного поиска. |
| Команды | /ideas, /status, /cancel, /new, /login (вход на сайт без пароля), /help |
| Глубокий разбор | Кнопка «🔬 Глубокий разбор (Opus)» на странице идеи: повторный разбор на Opus (≈ вдвое дороже), правки экономики сохраняются. |
| Отзыв | На странице идеи оставьте оценку и причину. Отметка памяти добавляет её к будущим исследованиям. Сохранение бесплатно. |
| План теста | Подготовка, сроки, ответственные, критерии остановки и фактические расходы сохраняются отдельно для каждой идеи. |
| Идея дня | Каждый день в заданное время бот сам ищет идею. Если достойной нет, честно пишет, почему. |

Рынок всегда подписан явно: «США (USA)» или «ОАЭ (UAE)». Данные одной страны не переносятся на другую.

## Как считается оценка /10

Оценка складывается из пяти частей: спрос 25%, готовность купить 15%, возможность отличиться от конкурентов 15%, экономика 30%, выполнимость 15%. Экономику считает код (маржа после рекламы), остальные части оценивает модель с обоснованием. **Оценка — это не вероятность успеха.**

Стоп-факторы ограничивают оценку сверху:

- Жёсткий стоп: платежи или законный запуск невозможны, убыток с заказа ещё до рекламы (CM1 ≤ 0) или сезон уже пропущен. Тогда оценка не выше 3, вывод «отклонить».
- Мягкий стоп: не хватает бюджета или часов, либо заказ убыточен после рекламы (CM2 ≤ 0). Тогда оценка не выше 4.5, вывод «доработать».
- Мало данных с источниками. Тогда вывод «недостаточно данных».

Рынок выбирает код: лучший балл среди рынков, прошедших обязательные условия. Все правила видны на странице разбора.

## Расходы

- Claude Sonnet 5.5: $2 за млн входных токенов и $10 за млн выходных. Веб-поиск: $10 за 1000 поисков.
- Расходы каждого этапа видны в журнале. Поиск передаёт модели результаты напрямую, без промежуточного кода фильтрации. Рыночный шаг ограничен 3 поисками, производство 2 поисками. Ответы и источники кешируются. Пересчёт сохранённых данных и отзывы выполняются бесплатно.
- Обычный выбор идеи и анализ рынка выполняет Sonnet; разбор ввода и сбор условий производства — Haiku. Явный глубокий разбор сохраняет Opus. Для моделей 5.5 задан ограниченный effort, чтобы короткие структурированные ответы не расходовали весь лимит на служебную обработку. Новые расходы Haiku 5.5 учитывают порог 100 000 входных токенов, для Sonnet/Opus 5.5 чтение кеша — 5% входного тарифа. Старые записи расходов не переписываются.
- Лимиты задаются в настройках. По умолчанию $1.5 на исследование и $50 в месяц. Перед вызовом резервируется оценка максимального расхода, в том числе для продолжения ответа. Резерв зависит от настроенных тарифов и предела входного контекста. Итог сверяется с использованием API. Подбор идеи дня и её дочерние исследования имеют общий бюджет.
- Отдельно платятся VPS, Shopify, образцы и реклама.

## Установка (делается один раз, файлы трогать не нужно)

1. **VPS на Fornex**: Ubuntu 24.04, от 2 ГБ RAM. Понадобятся IP-адрес и SSH-ключ или пароль root.
2. **Домен (желательно)**: создайте A-запись вида `research.вашдомен.com`, указывающую на IP сервера. С доменом будет HTTPS, и Telegram без проблем откроет ссылку-кнопку. Без домена сайт будет доступен по `http://IP`.
3. **Telegram-бот**: в @BotFather выполните `/newbot` и сохраните токен.
4. **Claude API**: на console.anthropic.com создайте API-ключ и пополните баланс ($10–20 для начала).
5. **GitHub**: создайте приватный репозиторий и подключите его к Claude, чтобы код загружал я.
6. **Секреты**: репозиторий → Settings → Secrets and variables → Actions → New repository secret:

| Секрет | Значение |
|---|---|
| `VPS_HOST` | IP сервера |
| `VPS_USER` | `root` |
| `VPS_SSH_KEY` *или* `VPS_PASSWORD` | приватный SSH-ключ или пароль root |
| `SITE_URL` | `https://research.вашдомен.com` (или `http://IP`) |
| `SITE_ADDRESS` | `research.вашдомен.com` (пусто, если домена нет) |
| `ADMIN_EMAIL`, `ADMIN_PASSWORD` | вход на сайт |
| `SECRET_KEY` | любая случайная строка из 40+ символов |
| `TELEGRAM_BOT_TOKEN` | токен бота |
| `ANTHROPIC_API_KEY` | ключ Claude API |
| `OPENAI_API_KEY` | необязательно, для голосовых |

7. **Деплой**: запустится сам после загрузки кода (вкладка Actions → Deploy to VPS). Сначала прогоняются тесты, затем на сервер ставится Docker и запускаются сайт, бот, воркер и HTTPS.
8. **Привязка бота**: откройте сайт → войдите → «Настройки» → «Telegram» → отправьте боту `/start КОД`. Затем заполните профиль: бюджет, часы, навыки, страна, платежи.

## Как дальше дорабатывать без вас

Вы пишете в Claude, что нужно поменять. Я меняю код в репозитории, и после загрузки GitHub Actions сам прогоняет тесты и обновляет бота на сервере. Данные (база в `data/`) при обновлении сохраняются. База копируется каждый день, хранятся 14 последних копий (`data/backups`).

Пароли и ключи не нужно присылать в чат: они хранятся только в GitHub Secrets и в `.env` на сервере.

## Разработка

```bash
pip install -r requirements.txt
python -m pytest -q                       # тесты (используют ДЕМО-модель)
FAKE_LLM=1 ADMIN_EMAIL=a@b.c ADMIN_PASSWORD=x uvicorn app.web.main:app   # сайт с ДЕМО-данными
python -m app.worker                      # воркер
python -m app.bot                         # бот
```

Устройство: `app/web` — сайт (FastAPI), `app/bot.py` — Telegram (aiogram, polling), `app/worker.py` — очередь и расписание, `app/research.py` — исследование, `app/economics.py` — калькулятор, `app/scoring.py` — оценка, `app/sources.py` — источники, `app/prompts.py` — промпты исследователя. База — SQLite.


## Аналитика и сохранённые предпочтения

Подключения настраиваются в кабинете на `/sources`. Нужны API login и API password DataForSEO, ключ SearchApi и ключ Keepa. Ключ Census бесплатный и активируется по email. Ключи вводятся в защищённые поля, хранятся в SQLite зашифрованными через Fernet и привязаны к владельцу. На страницу они не возвращаются. Для расшифровки нужен прежний постоянный SECRET_KEY. Поддерживается прежняя настройка через DATAFORSEO_LOGIN, DATAFORSEO_PASSWORD, SEARCHAPI_API_KEY, KEEPA_API_KEY и CENSUS_API_KEY в окружении.

DataForSEO автоматически получает пятилетние ряды Google Trends, объём и месячную динамику запросов Google/Bing. SearchApi получает активные объявления Meta и предложения Google Shopping по нужной стране. Keepa получает данные сопоставимых ASIN Amazon.com, историю цен и доступные показатели спроса. Keepa не поддерживает Amazon.ae. TikTok Commercial Content Library не покрывает США/ОАЭ, поэтому её европейские показатели в сравнение этих рынков не подставляются.

После сохранения ключа нажмите «Проверить подключение». Проверка делает один запрос в рамках лимитов. Для Keepa нужна ссылка Amazon.com с ASIN в одной из ваших идей. На странице готового разбора кнопка «Обновить данные API» обновляет измерения и расчёты без вызова модели. Полное «Обновить разбор» также передаёт полученные измерения модели. Без ключей API помечены как ожидающие подключения, показатели не выдумываются.

Вкладка «На чём основан ответ» показывает краткие измерения, страну, единицы, период, источник, расчёты, неизвестные условия и комментарии, переданные модели в этой версии. Для Trends доступен график. Объёмы близких ключей не суммируются. Объём запросов, количество объявлений, sales rank и прогноз заказов разделены. По умолчанию рекомендация теста требует аналитических измерений.

Без API-ключей ежедневный поиск продолжает предварительный отбор по проверяемым публичным источникам. Объёмы поиска и Trends остаются неизвестными. Это не блокирует подготовку разбора, но положительный допуск к запуску требует подтверждения данных. Проверенные цены предложений показываются отдельно: диапазон, медиана по независимым продавцам и сравнение с нашей ценой. Комплектация может отличаться; предложения не доказывают продажи. Безубыточные CAC/ROAS считаются кодом по экономическим допущениям.

План на 30 дней удалён. Названный товар исследуется с явно указанными допущениями по размерам и комплектации; вопросы об этих деталях не останавливают идею дня. В группе бот реагирует на /new, «Идея:», «Проверь…», упоминание бота или ответ к сообщению об идее, пропускает обычную переписку и сообщения ботов. «Ты о чём?» бесплатно показывает контекст идеи при любом статусе. Кнопка «Продолжить сохранённый разбор» возвращает ту же задачу в очередь, сохраняя её кеш, расходы и общий бюджет.

Расход DataForSEO из ответа API включается в общий бюджет; по умолчанию лимит аналитических данных 0.35 USD на разбор и 12 запросов. Кредиты SearchApi и токены Keepa учитываются отдельно от долларов, их подписки оплачиваются отдельно. Лимит запросов за месяц 300, токенов Keepa 100; значения меняются в настройках. При неопределённой стоимости ошибки DataForSEO резервируется консервативная оценка. Автоматической повторной оплаты неоднозначного запроса нет. Данные кешируются на сутки (объявления/цены), неделю (Trends) и 30 дней (объёмы). Ежедневный отбор проверяет кандидатов пакетно через аналитические API, а полное исследование повторно использует подходящие свежие измерения.

Память комментариев выбирает релевантные и недавние отзывы из всей сохранённой истории. Полный текст выбранных отзывов и их ID сохраняется в снимке контекста версии. Возобновлённый платный запрос использует прежний снимок, новые комментарии не приписываются уже полученному ответу. В форме отзыва можно выбрать обязательные предпочтения — круглогодичный товар, повторная покупка, исключение хрупкого или ручной работы над каждым заказом. Их соблюдение проверяется кодом и влияет на допуск. Это сохранение контекста и правил, без изменения весов модели.

По умолчанию первыми рассматриваются США и круглогодичные товары. Приоритет рынка меняется в настройках. При сопоставимых оценках учитывается предпочтение владельца. Неподтверждённые условия запуска блокируют рекомендацию теста.

Google Trends импортируется CSV с проверкой выбранной страны. Keyword Planner принимает CSV и сохраняет исходные диапазоны. Для автоматического Keyword Planner задаются GOOGLE_ADS_DEVELOPER_TOKEN, GOOGLE_ADS_CUSTOMER_ID, GOOGLE_ADS_CLIENT_ID, GOOGLE_ADS_CLIENT_SECRET и GOOGLE_ADS_REFRESH_TOKEN. При необходимости добавляется GOOGLE_ADS_LOGIN_CUSTOMER_ID. Доступ и квоты Google Ads подтверждаются при первом вызове. Без этих данных кабинет показывает ожидание подключения.

U.S. Census ACS загружается через API и используется как демографический контекст. С мая 2026 для запросов данных обязателен бесплатный активированный CENSUS_API_KEY, получить его можно на https://api.census.gov/data/key_signup.html. Без ключа источник отмечен как требующий подключения, запросы не отправляются. UN Comtrade кешируется на 30 дней с актуальным скользящим периодом и ограниченным повтором при 429. Доступность каждого источника показана в кабинете.

Ежедневная проверка сохранённых разборов обновляет проверку источников. Полное исследование обновляется раз в 7 дней в пределах бюджета. Архивные идеи исключены. Импорт данных ставит бесплатный пересчёт в очередь.

Данные обновляются миграцией SQLite при запуске. Исторические версии сохраняются. Старые отчёты пересчитываются по новым правилам без платной генерации. Отзывы содержат версию отчёта и управляемую отметку памяти. Одновременные правки финансовых форм проверяют версию отчёта.
