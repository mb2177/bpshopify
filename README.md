# Shopify Research Bot: Telegram и веб-кабинет

Бот проверяет идеи небольшого товарного бизнеса на Shopify для двух рынков: **США (USA)** и **ОАЭ (UAE)**. Дропшиппинг исключён.

- **Telegram** нужен только для ввода. Пришлите идею текстом, ссылкой, фото или голосом. Бот подтвердит приём, а когда разбор будет готов, пришлёт оценку **X/10**, вывод, первый рынок и **ссылку на полный разбор**.
- **Сайт** хранит всё: историю идей, полные разборы, конкурентов, производство, экономику, версии, источники.

## Как пользоваться

| Действие | Как |
|---|---|
| Новая идея | Написать боту: «Проверь идею: кастомные футболки для свадеб, конкуренты в Дубае». Можно прислать ссылку, фото или альбом. |
| Уточнить идею | Ответить (reply) на сообщение бота об идее: «а если партия 50 шт?», «найди конкурентов в Дубае», «не хотим покупать оборудование». То же можно сделать на сайте в разделе «Уточнить». |
| Поменять цифры | Сайт → идея → «Экономика» → «Изменить параметры». Пересчёт мгновенный, без платного поиска. |
| Команды | /ideas, /status, /cancel, /new, /login (вход на сайт без пароля), /help |
| Глубокий разбор | Кнопка «🔬 Глубокий разбор (Opus)» на странице идеи: повторный разбор на Opus (≈ вдвое дороже), правки экономики сохраняются. |
| Идея дня | Каждый день в заданное время бот сам ищет идею. Если достойной нет, честно пишет, почему. |

Рынок всегда подписан явно: «США (USA)» или «ОАЭ (UAE)». Данные одной страны не переносятся на другую.

## Как считается оценка /10

Оценка складывается из пяти частей: спрос 25%, готовность купить 15%, возможность отличиться от конкурентов 15%, экономика 30%, выполнимость 15%. Экономику считает код (маржа после рекламы), остальные части оценивает модель с обоснованием. **Оценка — это не вероятность успеха.**

Стоп-факторы ограничивают оценку сверху:

- Жёсткий стоп: платежи или законный запуск невозможны, убыток с заказа ещё до рекламы (CM1 ≤ 0) или сезон уже пропущен. Тогда оценка не выше 3, вывод «отклонить».
- Мягкий стоп: не хватает бюджета или часов, либо заказ убыточен после рекламы (CM2 ≤ 0). Тогда оценка не выше 4.5, вывод «доработать».
- Мало данных с источниками. Тогда вывод «недостаточно данных».

Рынок выбирает код: лучший балл среди рынков, прошедших обязательные условия. Все правила видны на странице разбора.

## Расходы

- Claude Sonnet 5.5: $2 за млн входных токенов и $10 за млн выходных. Веб-поиск: $10 за 1000 поисков.
- Полный разбор стоит примерно **$0.5–1**. Это оценка: фактические расходы видны на сайте в разделе «Журнал» после первых запусков.
- Лимиты задаются в настройках. По умолчанию: $1.5 на один разбор и $50 в месяц. При исчерпании бот останавливается и сообщает об этом.
- Отдельно платятся VPS, Shopify, образцы и реклама.

## Установка (делается один раз, файлы трогать не нужно)

1. **VPS на Fornex**: Ubuntu 24.04, от 2 ГБ RAM. Понадобятся IP-адрес и SSH-ключ или пароль root.
2. **Домен (желательно)**: создайте A-запись вида `research.вашдомен.com`, указывающую на IP сервера. С доменом будет HTTPS, и Telegram без проблем откроет ссылку-кнопку. Без домена сайт будет доступен по `http://IP`.
3. **Telegram-бот**: в @BotFather выполните `/newbot` и сохраните токен.
4. **Claude API**: на console.anthropic.com создайте API-ключ и пополните баланс ($10–20 для начала).
5. **GitHub**: создайте приватный репозиторий и подключите его к Claude, чтобы код загружал я.
6. **Секреты**: репозиторий → Settings → Secrets and variables → Actions → New repository secret:

| Секрет | Значение |
|---|---|
| `VPS_HOST` | IP сервера |
| `VPS_USER` | `root` |
| `VPS_SSH_KEY` *или* `VPS_PASSWORD` | приватный SSH-ключ или пароль root |
| `SITE_URL` | `https://research.вашдомен.com` (или `http://IP`) |
| `SITE_ADDRESS` | `research.вашдомен.com` (пусто, если домена нет) |
| `ADMIN_EMAIL`, `ADMIN_PASSWORD` | вход на сайт |
| `SECRET_KEY` | любая случайная строка из 40+ символов |
| `TELEGRAM_BOT_TOKEN` | токен бота |
| `ANTHROPIC_API_KEY` | ключ Claude API |
| `OPENAI_API_KEY` | необязательно, для голосовых |

7. **Деплой**: запустится сам после загрузки кода (вкладка Actions → Deploy to VPS). Сначала прогоняются тесты, затем на сервер ставится Docker и запускаются сайт, бот, воркер и HTTPS.
8. **Привязка бота**: откройте сайт → войдите → «Настройки» → «Telegram» → отправьте боту `/start КОД`. Затем заполните профиль: бюджет, часы, навыки, страна, платежи.

## Как дальше дорабатывать без вас

Вы пишете в Claude, что нужно поменять. Я меняю код в репозитории, и после загрузки GitHub Actions сам прогоняет тесты и обновляет бота на сервере. Данные (база в `data/`) при обновлении сохраняются. База копируется каждый день, хранятся 14 последних копий (`data/backups`).

Пароли и ключи не нужно присылать в чат: они хранятся только в GitHub Secrets и в `.env` на сервере.

## Разработка

```bash
pip install -r requirements.txt
python -m pytest -q                       # тесты (используют ДЕМО-модель)
FAKE_LLM=1 ADMIN_EMAIL=a@b.c ADMIN_PASSWORD=x uvicorn app.web.main:app   # сайт с ДЕМО-данными
python -m app.worker                      # воркер
python -m app.bot                         # бот
```

Устройство: `app/web` — сайт (FastAPI), `app/bot.py` — Telegram (aiogram, polling), `app/worker.py` — очередь и расписание, `app/research.py` — исследование, `app/economics.py` — калькулятор, `app/scoring.py` — оценка, `app/sources.py` — источники, `app/prompts.py` — промпты исследователя. База — SQLite.
